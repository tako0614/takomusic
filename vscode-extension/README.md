# TakoMusic VSCode Extension

Language support for `.mf` files:

- Syntax highlighting
- LSP diagnostics, hover, completion
- Formatting and organize imports

## Quick Start

1. Open a workspace with `.mf` files.
2. Open `main.mf`.
3. Use formatting and code actions from the editor.
